# Загрузка PNG-спрайтов в Бадимку

Игра теперь умеет подменять процедурную графику на готовые PNG-ассеты. Процедурка остаётся как fallback — для тех спрайтов, которых нет в PNG, игра рисует их кодом как раньше. Можно подменить часть зданий и постепенно докупать/догенерировать остальные.

## Два способа загрузить спрайты

### Способ 1 — через интерфейс игры (работает где угодно, в т.ч. при открытии HTML двойным кликом)

1. Открой игру
2. Меню → ❓ Помощь (или просто Help)
3. В самом низу: «📁 Выбрать PNG-файлы»
4. Выбери одно или несколько PNG (можно сразу все 50+)
5. Игра подменит соответствующие здания, появится тост «Загружено: N»

### Способ 2 — через папку (требует локальный http-сервер)

1. Создай папку `sprites/` рядом с файлом `badimka.html`
2. Положи туда PNG-файлы
3. Запусти локальный сервер в этой папке:
   ```
   python -m http.server 8000
   ```
   и открой `http://localhost:8000/badimka.html`
4. Игра автоматически подгрузит спрайты при старте

> **Почему нужен сервер.** Браузеры при открытии HTML по `file://` блокируют `fetch` к локальным файлам (CORS). Меню «Выбрать PNG-файлы» обходит это ограничение через `<input type=file>` — оно работает всегда.

## Правила именования файлов

Имя файла должно начинаться с ID объекта в игре. Дальше можно добавлять любой суффикс (`_hovel`, `_v2`, `_final` и т.п.) — это не помешает распознаванию.

### Дома (7 уровней эволюции)
- `house_lvl1.png` или `house_lvl1_hovel.png` → лачуга
- `house_lvl2.png` → хижина
- `house_lvl3.png` → деревянный дом
- `house_lvl4.png` → каменный дом
- `house_lvl5.png` → фахверк двухэтажный
- `house_lvl6.png` → усадьба
- `house_lvl7.png` → дворянский дом

Также сработают варианты `house_1.png`, `house_lvl1_anything.png` и т.п.

### Здания (точное имя ID = имя файла)
Полный список ID:
```
farm garden pasture fisher hunter mill bakery dairy vineyard
lumber quarry claypit ironmine coalmine
sawmill carpenter smelter smith weaponsm weaver tailor jeweler scriptor
well market church school hospital tavern theatre fair
barracks tower wall arsenal
townhall taxoffice court tradepost palace
```

Примеры: `tavern.png`, `church.png`, `townhall.png`, `farm_v3.png`, `palace_final.png`.

### Природа
- `tree_oak.png` → лиственное дерево (вариант 1)
- `tree_oak2.png` → лиственное дерево (вариант 2)
- `tree_dark.png` → тёмное лиственное
- `tree_pine.png` → сосна
- `rock.png` → камни/валуны

## Требования к PNG

- **Прозрачный фон обязателен** (PNG с alpha-каналом). Если фон чёрный/белый/цветной — игра отобразит его как непрозрачную плашку
- **Один объект на файл** — не делай атласов или сборок
- **Любое разрешение** — игра автоматически впишет PNG в нужный размер с сохранением пропорций
- **Якорь определяется автоматически** — игра находит нижнюю центральную точку непрозрачной области и использует её как точку касания с землёй

## Если что-то пошло не так

- **«Не распознано: N»** — имя файла не совпадает ни с одним ID. Проверь список выше, переименуй
- **Здание встаёт криво / пересекает соседние** — у PNG слишком большая «подложка» (трава, тень-нимб). Обрежь PNG так, чтобы непрозрачная область плотно облегала здание + небольшой контактный shadow снизу
- **Спрайт остался процедурным после загрузки** — открой консоль браузера (F12), проверь сообщения `[sprites]`. Возможные причины: имя файла не сматчилось, PNG битый, или браузер не смог прочитать пиксели (CORS — но это только для file://)

## Откат к процедурной графике

Просто обнови страницу (F5). Подменённые спрайты живут только до перезагрузки. Сохранения игры (прогресс) при этом сохраняются — они отдельно в localStorage.

## Тайлы земли (новое)

Игра умеет подменять и текстуры земли. Имена файлов:
`tile_grass.png, tile_water.png, tile_river.png, tile_sand.png, tile_fert.png,
tile_forest.png, tile_hill.png, tile_mtn.png, tile_swamp.png, tile_road.png`

Требования: квадратная бесшовная (seamless/tileable) текстура «вид сверху», без
перспективы и объектов. Игра сама впишет её в изометрический ромб. Кладите в
`./sprites/` или загружайте через Помощь → «Выбрать PNG-файлы».
